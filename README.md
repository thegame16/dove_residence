# Dove Residence website

A single-page website for Dove Residence, Ahodwo Daban, Kumasi.

## Files
- `index.html` the whole site (no build step)
- `living-room.jpg`, `bedroom.jpg`, `bedroom-2.jpg`, `kitchen.jpg`, `bathroom.jpg`, `patio.jpg`, `exterior.jpg` the photos
- `logo.jpg` (optional) add your logo with this exact name and it replaces the text logo

## Put it online with GitHub Pages
1. Create a repository on GitHub.
2. Upload **all** the files in this folder to the repository root.
3. Go to Settings > Pages, choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. Your site appears at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` after a minute or two.

## Changing things
- Photos: replace a file with a new one of the same name.
- Text, phone numbers, email: open `index.html` and search for the text.
- Airbnb button: search for `OPTIONAL: add your Airbnb listing`, remove the comment markers and add your listing link.
